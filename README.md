# forja-website

Landing page estatica da FORJA, mantida localmente em `forja-academia/` e publicada publicamente como `forja-website`.

## Estrutura

- `index.html`: pagina unica com layout, estilos e scripts inline
- `assets/`: imagens e arquivos estaticos usados pela pagina

## Publicacao

- Repositorio GitHub: `voro-agency/forja-website`
- Projeto Vercel: `forja-website`

## Continuidade

1. Editar os arquivos locais em `forja-academia/`
2. Commitar na branch `main`
3. Executar push para `origin`
4. A Vercel publica automaticamente via integracao Git
