# Contexto do projeto

- Objetivo: demonstrar uma página de alta conversão para academia ou estúdio de performance.
- Tipo: projeto-conceito do portfólio VORO, não uma academia real.
- Stack: HTML, CSS e JavaScript em arquivo único, publicado na Vercel.
- Público: academias, boxes, estúdios e profissionais de performance.
- Restrições: não apresentar planos, depoimentos, métricas, equipe ou contatos fictícios como fatos; a conversão real deve levar para a VORO.
